OpenAN A2A Workflow Engine 0.1.0 Released

News · September 23, 2026 · by OpenAN

News Workflow Engine SDK PSOP Release

Highlights

This release delivers the A2A Workflow Engine SDK 0.1.0 for both Java and Python, providing protocol-layer scheduling — task dispatching, state sync, and result callbacks — based on PSOP DAGs and AgentCard Skills.

Business logic such as context construction and conditional routing is delegated to the application layer, keeping the SDKs business-agnostic and reusable across scenarios.
