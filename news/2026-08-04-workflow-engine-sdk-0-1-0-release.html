OpenAN Workflow Engine SDK 0.1.0 Released

News · August 4, 2026 · by OpenAN

News Workflow Engine SDK PSOP A2A-T

Overview

A lightweight SDK that handles protocol-layer scheduling (task dispatching, state sync, result callbacks) based on PSOP DAGs and AgentCard Skills. Business logic such as context construction and conditional routing is delegated to the application layer, keeping the SDK business-agnostic and reusable.
